Classement — Le Dernier Dîner

Collez un code final par ligne (ou plusieurs d'un coup). Pour chaque équipe, seul le meilleur score est gardé. Égalité : plus d'indices, puis la plus rapide. Une équipe qui a lancé plusieurs parties est signalée. Tout reste dans ce navigateur.

1. Au départ : enregistrer le code de chaque équipe

Une ligne par équipe : numéro puis code affiché par l'app (ex. « 7 MWZ »). Seuls les résultats dont le code correspond seront classés. Si une équipe redémarre sur un autre téléphone, ajoutez sa nouvelle ligne : son ancien code reste valable.
